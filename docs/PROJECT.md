# Tile Tales - Vision del Proyecto

## Concepto
**Tile Tales** (Historias de Azulejos) es una app para coleccionar, visualizar y componer con azulejos que encuentras por la calle. La idea nace de la belleza de los azulejos urbanos — patrones geometricos, ceramica artesanal, mosaicos historicos — y la voluntad de preservarlos digitalmente.

## Plataforma
- **Fase inicial**: Aplicacion web (Next.js)
- **Fase futura**: App nativa iOS

## Features core
1. **Captura**: Hacer fotos a azulejos que encuentras en la calle
2. **Galeria 3D**: Visualizar tu coleccion como cards con efecto 3D (rotacion, perspectiva, profundidad)
3. **Colecciones**: Organizar azulejos por ciudad, estilo, color, epoca...
4. **Compositor de fondos**: Mezclar varios azulejos para crear patrones/backgrounds tileable
5. **Detalle de azulejo**: Vista individual con metadata (ubicacion, fecha, notas)

## Estetica
- Interfaz limpia, fondo claro (off-white/beige)
- Cards con bordes redondeados y sombras suaves
- Efectos 3D sutiles: rotacion al hover/scroll, perspectiva
- Inspiracion en objetos fisicos: sellos, vinilos, sobres, carpetas
- Tipografia elegante, espaciada

## Inspiraciones visuales
Ver `/references/` y `docs/REFERENCES.md` para descripcion detallada de cada referencia.

Temas clave de las referencias:
- **Cards 3D con rotacion** (The Architect gallery) — efecto de galeria donde las cards rotan en el espacio
- **Formato sello/stamp** (bonjour.bio) — bordes dentados tipo sello postal para enmarcar items
- **Formato vinilo/disco** — fotos circulares con agujero central, grid de discos
- **Sobre/envelope reveal** — animacion de revelar contenido desde un sobre
- **Mini archive/libro** — coleccion tipo libro que se abre mostrando items
- **Folder 3D** — documentos saliendo de una carpeta con efecto de profundidad
- **Colecciones por categorias** — agrupacion visual tipo stamps con contador
